# Vision

`ai-first` should be a small continuity boost for normal AI-assisted development.

The owner keeps talking to agents the same way they already do. `ai-first` reduces repeated explanations by giving the agent durable local context, active work, backlog, ideas, decisions, and recent history.

The mission is to make the agent more autonomous without making the owner work harder. The owner steers direction; the agent carries more operational memory, maintenance, and execution load.

Non-goals:

- replacing existing agent skills;
- changing the natural-language owner-agent interaction;
- creating a template marketplace;
- requiring global CLIs, persistent binaries, `npx`, or `node_modules` inside `.ai-first`.
